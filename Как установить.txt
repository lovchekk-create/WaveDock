WaveDock 1.3 — музыкальный виджет для панели задач Windows 10/11
=================================================================

КАК ЗАПУСТИТЬ
1. Распакуй архив в любую папку (например, «Документы\WaveDock»).
2. Запусти WaveDock.exe — на панели задач появится квадрат с волнами.
3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер»:
   нажми «Подробнее» → «Выполнить в любом случае».
   (Программа без платной цифровой подписи, поэтому Windows её не знает.)

Ничего устанавливать не нужно — всё уже внутри WaveDock.exe.

УПРАВЛЕНИЕ
• Клик по квадрату — плеер (обложка, трек, перемотка, громкость)
• Средняя кнопка мыши — пауза
• Колесо мыши — следующий / предыдущий трек
• Ctrl + колесо — громкость
• Зажми и тащи квадрат — передвинуть по панели задач
• Правый клик — настройки, автозапуск с Windows, выход
• В плеере: кнопка «текст» — текст песни, синхронно с музыкой
• Шестерёнка — полная настройка: размер, цвета, волны, анимации и т.д.

ГОРЯЧИЕ КЛАВИШИ (работают в любой программе)
• Ctrl+Alt+Пробел (или Ctrl+Alt+P) — пауза
• Ctrl+Alt+→ / ← — следующий / предыдущий трек
• Ctrl+Alt+↑ / ↓ — громкость
• Ctrl+Alt+L — плеер с текстом песни

РАБОТАЕТ С
Spotify, Яндекс Музыка, YouTube и VK в браузере, SoundCloud, Медиаплеер Windows,
AIMP и любым плеером, который показывает трек в системной плашке громкости.

СТАТУС В DISCORD
Если Discord запущен, в профиле будет «Слушает WaveDock» с треком и обложкой.
Включается/выключается в настройках (раздел «Статус в Discord»).
Если не видно: Discord → Настройки → Конфиденциальность активности →
«Показывать текущую активность».

УДАЛИТЬ
Правый клик по квадрату → снять «Запускать вместе с Windows» → «Выход».
Потом просто удали папку. Настройки лежат в %AppData%\WaveDock.
